# 쇼츠 자동프로젝트2번째

나는 코딩 초보자야.
기존에 “TTS 쇼츠 대본 프롬프트 생성기”를 만들었지만, 이제는 새 프로젝트로 더 큰 방향의 앱을 만들고 싶어.

앱 이름:
쇼츠 자동 제작 OS

앱의 핵심 목적:
이 앱은 AI 쇼츠를 단순히 비슷한 형식으로 양산하는 도구가 아니라, 사용자가 다양한 영상 포맷을 설계하고, 트렌드 기반 아이디어와 직접 떠올린 독자적인 아이디어를 분리해서 관리하며, 최종적으로 쇼츠/TTS 콘텐츠 1개를 빠르게 제작할 수 있도록 돕는 작업대야.

최종 목표:
사용자가 버튼과 선택지를 따라가면서 아래 과정을 완료하게 만드는 것.

트렌드 또는 직접 아이디어 선택

쇼츠 주제 후보 3개 확인

후킹 문장 후보 3개 선택

대본 후보 3개 선택

제목/썸네일 후보 3개 선택

목소리 톤 후보 3개 선택

장면 구성 후보 3개 선택

저작권/수익화/반복 콘텐츠 위험 체크

최종 쇼츠 제작 패키지 내보내기

중요한 방향:
처음부터 실제 AI API, 자동 영상 생성, 자동 업로드는 만들지 마.
첫 번째 버전은 “쇼츠 제작 과정을 빠짐없이 관리하고, 후보 3개 중 선택하면서 최종 패키지를 만드는 노트북형 제작 OS”로 만들어줘.

전체 UI 구조:
NotebookLM, Notion, 생산성 도구 같은 느낌으로 만들어줘.
큰 노트북 카드들을 클릭해서 각 단계에 들어가고, 그 단계의 일을 완료하면 다시 나와서 다음 단계로 넘어가는 구조였으면 좋겠어.

메인 화면 구성:

상단: 앱 이름, 현재 프로젝트 진행률

중앙: 쇼츠 프로젝트 카드

하단 또는 오른쪽: 오늘 해야 할 다음 단계

새 프로젝트 만들기 버튼

프로젝트 개념:
프로젝트 하나는 쇼츠 영상 1개를 의미해.

프로젝트 정보:

프로젝트 제목

제작 루트: 트렌드 기반 / 내 아이디어 기반

콘텐츠 카테고리: AI, 자기계발, 돈/부업, 20대 현실 조언, 음악/창작, 공부, 사회현상

목표 플랫폼: 유튜브 쇼츠, 인스타 릴스, 틱톡

영상 길이: 30초, 60초

목표: 조회수 실험, 수익화 실험, 채널 성장, 브랜딩

프로젝트 안의 노트북 카드:
아래 노트북들을 카드 형태로 만들어줘.

트렌드 노트북

역할: 트렌드 키워드, 참고할 흐름, 사람들이 관심 가질 만한 고민 정리

내 아이디어 노트북

역할: 사용자가 갑자기 떠올린 독자적 쇼츠 아이디어 저장

이 아이디어를 새로운 영상 포맷으로 만들 수 있게 정리

포맷 라이브러리 노트북

역할: 여러 영상 형식을 저장

예: TOP5형, 반전 독백형, 비교형, AI 시대 해석형, 스토리형, 체크리스트형

주제 선택 노트북

역할: 주제 후보 3개 중 하나 선택

후킹 노트북

역할: 첫 1~2초 문장 후보 3개 중 하나 선택

대본 노트북

역할: 30초/60초 대본 후보 3개 중 하나 선택

제목/썸네일 노트북

역할: 제목 후보 3개, 썸네일 문구 후보 3개 중 선택

목소리 노트북

역할: TTS 목소리 톤 후보 3개 선택

예: 차분한 남자 저음, 빠른 정보 전달 톤, 감성적 나레이션 톤

장면 구성 노트북

역할: 자막, B-roll, 이미지, 화면 흐름 후보 3개 선택

다양성/원본성 체크 노트북

역할: 영상이 너무 비슷하거나 반복적이지 않은지 확인

체크 항목:

최근 만든 영상과 대본 구조가 너무 비슷하지 않은가?

같은 포맷을 너무 반복하고 있지 않은가?

내 해석이나 관점이 들어갔는가?

단순히 AI가 만든 흔한 문장만 모은 영상은 아닌가?

이미지, 영상, 음악 소스가 저작권상 안전한가?

AI로 만든 현실적인 장면이라면 공개가 필요한지 확인했는가?

제목과 썸네일이 허위 과장이나 낚시성만 있는 것은 아닌가?

최종 내보내기 노트북

역할: 선택한 내용을 한 번에 정리

최종 내보내기 항목:

최종 주제

최종 후킹 문장

최종 대본

TTS용 줄바꿈 대본

선택한 목소리 톤

제목 후보

썸네일 문구

장면 구성

편집 도구에 넣을 가이드

업로드 전 체크리스트

각 항목에는 복사하기 버튼을 넣어줘.
전체 복사하기 버튼도 만들어줘.

후보 3개 선택 구조:
각 노트북 안에서는 기본적으로 후보 A, 후보 B, 후보 C를 입력하거나 선택할 수 있게 해줘.
사용자가 하나를 선택하면 그 선택값이 최종 내보내기에 반영되게 해줘.

제작 루트:
반드시 두 가지 루트를 구분해줘.

트렌드 기반 제작

요즘 사람들이 관심 가질 만한 주제를 바탕으로 제작

내 아이디어 기반 제작

사용자가 직접 떠올린 독자적인 영상 형식을 바탕으로 제작

이 루트는 수익화 위험을 줄이고 콘텐츠 다양성을 높이기 위한 목적이 있음

상태 관리:
각 노트북은 아래 상태를 가지게 해줘.

시작 전

진행 중

완료

잠금

이전 단계가 완료되지 않으면 다음 단계는 잠금처럼 보이게 해줘.
단, 사용자가 원하면 잠금을 해제할 수 있는 “강제 진행” 버튼도 작게 넣어줘.

디자인:

NotebookLM처럼 노트북을 클릭해서 들어가는 느낌

Notion 같은 생산성 도구 느낌

PC에서 작업하기 좋은 넓은 화면

완료된 단계는 체크 표시

현재 해야 할 단계는 강조

너무 화려하지 않고 매일 쓰기 좋은 디자인

기술 제한:

아직 실제 AI API는 연결하지 마.

자동 영상 생성은 하지 마.

유튜브/인스타/틱톡 자동 크롤링은 하지 마.

로그인, 결제, 외부 데이터베이스는 넣지 마.

local storage로 현재 프로젝트 상태를 저장해줘.

초보자가 나중에 수정하기 쉽게 구조를 단순하게 만들어줘.

이번 첫 버전의 목표:
완성된 자동화 앱이 아니라, 쇼츠 영상 1개를 만들 때 어떤 단계를 끝냈고 무엇을 선택했는지 빠짐없이 관리할 수 있는 “노트북형 제작 파이프라인”을 만드는 것이야.

수정 후에는 이 앱을 어떻게 쓰면 되는지 초보자도 이해할 수 있게 설명해줘.
